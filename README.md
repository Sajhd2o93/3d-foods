# 3D Food Resource Pack

3D модели для еды и напитков в Minecraft (Java Edition 1.21.5 - 26.3+).

## Описание
Ресурспак заменяет стандартные плоские спрайты еды на объемные 3D-модели при удержании в руке, выпадении в мире и размещении на стойках для брони, сохраняя привычные 2D-иконки в инвентаре/GUI.

- **Автор**: White_GK
- **Поддерживаемые форматы ресурспаков**: 46 - 120 (Minecraft 1.21.4 - 1.21.5 - 26.3+)
- **Текущая версия**: v1.6

## Структура репозитория
- `src_pack/` — исходники ресурспака (`pack.mcmeta`, `pack.png`, `assets/`).
- `j/` — организованный каталог моделей и текстур, сгруппированных по отдельным предметам еды.
